# 3D 투석기 공성전

태블릿을 앞뒤로 기울여 발사각, 좌우로 기울여 방향을 정하고, 화면을 아래로 당겨 힘을 조절해 성을 공격하는 3D 게임입니다.

- 실행 주소: https://goodssam012.github.io/catapult-siege/
- 기울기 센서는 https 주소에서만 동작합니다 (iPad는 권한 허용 필요).

## 혼자 하기

성 안에 나타나는 물건을 돌 10개로 맞혀 점수를 얻습니다. 성벽과 탑은 돌에 맞은 만큼 부서집니다.

## 1:1 대전 (태블릿 2대)

1. 한 사람이 **⚔️ 1:1 대전 → 방 만들기**를 누르면 4자리 방 번호가 나옵니다.
2. 다른 사람은 같은 화면에서 그 번호를 넣고 **참가하기**를 누릅니다.
3. 방장이 먼저 쏘고, 한 번씩 번갈아 쏩니다.
4. 상대 성 안의 👑 왕관을 먼저 맞히면 승리! 둘 다 돌 10개를 쓰면 상대 성을 더 많이 부순 쪽이 이깁니다.

두 태블릿은 무료 공용 서버(PeerJS)로 연결됩니다. 학교 와이파이에서 연결이 안 되면 휴대폰 핫스팟 등 다른 네트워크로 시도해 보세요.
